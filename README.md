# ☕ Java Dojo

> A place to learn, practice, experiment, and master Java.

This repository is my personal **Java learning dojo**.

Here I document my journey from Java fundamentals to advanced topics through:

* 📚 theory
* 💻 practical exercises
* 🧪 experiments
* 🧩 algorithms
* 🗄️ SQL
* 🏗️ projects

The goal is not simply to learn how to write Java code, but to understand **how Java works and why it works this way**.

## 🧪 Experiments

An important part of the dojo is experimentation.

Instead of only reading about a concept, I try to reproduce it with code and understand what happens under the hood.

Examples:

* integer overflow
* floating-point representation
* `BigDecimal`
* `equals()` / `hashCode()`
* `HashMap` internals
* String Pool
* garbage collection
* multithreading
